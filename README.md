SuiviContrats
=============

Projet Xcode SwiftUI iOS minimal généré automatiquement.

Ouvrir dans Xcode :

    open SuiviContrats.xcodeproj

Ce projet contient :
- SuiviContratsApp.swift (point d'entrée SwiftUI)
- ContentView.swift (vue initiale)
- Info.plist
- Assets.xcassets (avec AppIcon stub)
- SuiviContrats.xcodeproj/project.pbxproj (fichier projet Xcode minimal)

Remarque : ce projet est un template minimal pour démarrer le développement. Ajuster le bundle identifier, les signatures et les cibles dans Xcode avant de lancer sur un appareil.
